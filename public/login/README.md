# RLA Login Hero Images

Drop photos here to have them appear on the login page slideshow.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

Recommended size: 1200 × 1600 px (portrait) or 1600 × 1200 px (landscape), ≤ 500 KB each.

The slideshow picks up any image in this folder automatically — no code changes needed.
See `/src/lib/login-config.ts` for rotation interval and other settings.

Photo ideas:
- Students in STEM / maker activities
- Leadership programs
- Entrepreneurship projects
- Community service
- Classroom learning
- PE and outdoor activities
- Parent events / Discovery Days
- Graduation ceremonies
- Field trips
- Chapel / faith activities
